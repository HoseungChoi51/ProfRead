# AfterDraft v0.4.0 — Academic manuscripts become reading workspaces

AfterDraft v0.4.0 adds a browsing-first academic import pipeline for arXiv
HTML, Word manuscripts, and LaTeX projects. Conversion remains rule-based and
deterministic; bounded LLM/VLM review is an optional second opinion that
surfaces visible omissions, broken associations, and layout problems without
granting a model permission to rewrite scholarly content.

## Academic import workflow

- Import an arXiv ID or official URL, a DOCX manuscript, a standalone TeX
  source, or a LaTeX project ZIP.
- Follow durable asynchronous stages, inspect warnings and evidence, choose an
  entry file for multi-entry archives, and publish only after preview.
- Preserve the source and conversion provenance while normalizing the result
  into AfterDraft's existing sanitized HTML, local assets, stable blocks,
  search index, annotations, revisions, and exports.
- Continue to receive a reviewable draft when a converter's optional source
  rendering or a model provider is unavailable.

## Academic semantics

- Native inline and display MathML survives sanitization and indexing.
- Safe fragment links, HTTPS citations, mail links, figures, tables, captions,
  footnotes, local images and fonts, and safe YouTube embeds remain usable.
- Hidden Word/Zotero field instructions are excluded from reader and model
  text, while rendered citations and bibliography entries are preserved.
- Print-only columns, page sizes, running chrome, and page breaks are flattened
  into a responsive reading view.

## Conversion worker

A credential-free internal sidecar contains Pandoc, LaTeXML, LibreOffice,
Poppler, and Chromium. It has no host port, Docker socket, application data
mount, or outbound network. Compose runs it as a non-root process with a
read-only root filesystem, dropped capabilities, bounded temporary storage,
CPU, memory, process, request, output, and execution limits.

DOCX conversion inventories OOXML before invoking Pandoc. TeX conversion uses
LaTeXML first and Pandoc as a bounded fallback. Chromium produces deterministic
desktop and narrow captures plus DOM metrics; Poppler or LibreOffice can
provide source-reference images without exposing conversion tools to the web
process.

## Complementary model review

- GPT-5.6 Luna handles manifest and outline triage.
- GPT-5.6 Terra handles semantic checks.
- GPT-5.6 Sol handles visual assessment.

Each request uses a strict structured findings contract, explicit evidence
identifiers, no web or executable tools, no provider fallback, and API response
storage disabled. Imports record actual coverage and report partial review when
text, evidence, calls, or provider availability prevent complete inspection.
Only high-confidence presentation repairs corroborated by deterministic DOM
measurements can be accepted or applied automatically.

## Final-touch editing

Edit mode can now correct heading levels and alt text, set responsive object
width/alignment/folding/enlargement, and safely move a visual before or after a
chosen destination. Caption edits preserve rich MathML and links. Table scroll
wrappers, figures, and captions remain structural units during layout changes.

## Validation

The release gate includes real scientific Word manuscripts with dense inline
and display equations, seven figures, two tables, Zotero citations, a
36-entry bibliography, tracked changes, mixed caption conventions, a Word
footnote, and IEEE template chrome. Fixture sources and generated conversion
artifacts remain private and are not committed.

## Migration and recovery

Database migrations 13 and 14 add durable import jobs, findings, evidence
decisions, and repair provenance. The worker is stateless; the existing
`afterdraft-data` Docker volume remains the complete backup and restore unit.
A pre-upgrade snapshot is required before deploying this release.
