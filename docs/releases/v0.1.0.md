# AfterDraft v0.1.0 — MVP

Released: 2026-08-11

AfterDraft v0.1.0 is the first MVP release of the private, self-hosted reading
workspace. It turns imported HTML articles into a durable environment for
reading, asking AI-assisted questions, preserving discussions and study
artifacts, editing the source presentation, and exporting the accumulated
work.

## Highlights

- A private article library with HTML and ZIP import, groups, full-text search,
  reading progress, version tracking, and safe deletion.
- A focused reader with anchored discussions, a resizable entry sidebar,
  responsive narrow-screen behavior, and Markdown-rendered answers.
- Selection actions for Copy, Define, Explain, Explain for a 14-year-old, Ask,
  Highlight, Compact, TL;DR, Half-page, Visual recap, Visualize, and Research.
- Configurable GPT-5.6 task routing, per-request model overrides, streaming
  responses, context tiers, editable prompts, and persistent behavior settings.
- Revisioned direct editing for article text, formatting, foldable sections,
  captions, and proportional image resizing.
- Self-contained HTML, Markdown, and PDF study exports, with optional full
  discussion history.
- Docker deployment with persistent SQLite/filesystem state, health checks,
  backup and restore documentation, and a one-command rebuild/restart helper.

## Article library and import

- Import self-contained `.html`/`.htm` files or ZIP bundles containing HTML,
  local CSS, fonts, images, SVG, tables, and video assets.
- Choose the intended entry document when a ZIP contains multiple HTML files.
- Deduplicate identical imports by content hash and retain new source versions
  instead of overwriting existing material.
- Preserve bundled styling and rewrite local asset references to immutable,
  server-managed assets.
- Retain approved native video and privacy-conscious YouTube embeds while
  rejecting unsupported remote embeds.
- Organize articles into named groups. Groups can be created, renamed, and
  deleted without deleting their articles; articles can be moved back to the
  ungrouped shelf at any time.
- Search indexed article text, AI answers, and derived artifacts with SQLite
  FTS5 and result-type filters.
- See article version, token estimate, checked-highlight count, and reading
  progress directly from the library.
- Permanently delete an article only through title-confirmed deletion. The
  cleanup covers imported versions, edits, assets, discussions, annotations,
  artifacts, search records, exports, and generated images while leaving
  server backups available for recovery.

## Reader and selection workflow

- Read sanitized content inside a CSP-restricted iframe that retains the
  article's local styling and media.
- Resize the discussion/sidebar area with a keyboard-accessible divider; use a
  synchronized drawer layout on narrow screens.
- Persist reading progress and reopen the most recently active material.
- Select article text to open actions for:
  - **Copy** — copies the exact passage, confirms with a `Copied` label, and
    falls back when the modern Clipboard API is blocked.
  - **Define** — creates or reopens a definition linked to the selected term.
  - **Explain** and **Explain for a 14-year-old** — produce audience-appropriate
    explanations.
  - **Ask** — sends a free-form question grounded in the selected passage.
  - **Highlight** — creates a checked local annotation without calling an AI
    model.
  - **Compact**, **TL;DR**, and **Half-page** — derive shorter study material.
  - **Visual recap** and **Visualize** — create structured visual knowledge
    outputs.
  - **Research** — explicitly enables the configured web-research route.
- Select images, SVG, tables, figures, and videos as visual anchors. Supported
  tables and figures include a captured visual representation for vision work.
- Override the routed model for an individual selection request.
- Click an article anchor or an entry to synchronize navigation between the
  source passage and its discussion.
- Render assistant Markdown with tables, links, and common formatting while
  ignoring raw HTML and remote model-supplied images.
- Stop an in-progress streamed response from the reader.

## Discussions and knowledge artifacts

- Keep durable threads rooted in article selections.
- Ask nested questions about individual assistant messages and reply within an
  existing thread while retaining the active context branch.
- Distinguish ordinary discussions, definitions, and manually checked
  highlights in the article.
- Generate TL;DR, half-page, compact, and visual-recap artifacts at document,
  section, answer, or thread scope where applicable.
- Treat document-level TL;DR, half-page, and visual recap outputs as singleton
  views that can be regenerated without cluttering the sidebar with obsolete
  copies.
- Pin or unpin artifacts for later use and include promoted artifacts in study
  exports and relevant future context.
- Render structured diagrams and visual recaps as accessible HTML/SVG; visual
  recaps can include a generated image when the configured provider supports
  image generation.
- Preserve source references, run metadata, citations, tool events, fallback
  attempts, latency, and token usage in the persistent knowledge model.

## AI routing, prompts, and context

- Use native OpenAI Responses, generic OpenAI-compatible Chat Completions, or
  OpenRouter-compatible provider definitions.
- Configure provider endpoints and environment-variable key references without
  returning or storing secret key values in the browser or database.
- Route each user-facing action to a configured GPT-5.6 model and show model
  readiness in the settings workspace.
- Stream response deltas and expose the selected provider, model, context tier,
  enabled tools, and fallback state in the reader.
- Build quick/brief, study, canonical, and branch-digest context tiers so long
  articles and conversations fit the selected model without silent truncation.
- Cache article contexts in background jobs and invalidate dependent caches
  when context settings or relevant prompts change.
- Edit 30 source-controlled prompt components from the UI, grouped into action
  requests, action contracts, context assembly, scope, routing, and structured
  output repair.
- Validate required `{{variables}}`, reject unknown placeholders, apply prompt
  overrides to the next request, and reset any template to its source default.
- Configure full-article thresholds, reserved prompt budget, quick/study
  context sizing, conversation ancestry, and digest excerpt sizes from the
  **Context & advanced** settings tab.
- Reset behavior settings to source defaults; only overrides are stored.

## Revisioned article editing

- Enter edit mode without modifying the immutable imported source file.
- Click supported text and heading blocks to edit them directly in place.
- Apply bold, italic, and underline formatting to exact text ranges.
- Convert heading sections into foldable sections and choose their open/closed
  state.
- Add or update labels, numbers, and captions for figures, tables, images, SVG,
  and video blocks.
- Select an imported raster image and drag its resize handle to set a safe,
  proportional width within the article.
- Review pending operations before saving or cancel the session to reload the
  latest saved revision.
- Store every save as an immutable edit revision with a summary and timestamp.
  Browse history and restore an earlier revision without erasing later history.
- Use the effective edited article for reading, AI context, search, and exports.

## Export and portability

- Export self-contained annotated HTML with embedded local assets, checked
  highlights, notes, and promoted artifacts.
- Optionally include the full discussion transcript in HTML.
- Export a Markdown study notebook with source metadata, highlights,
  footnotes, promoted artifacts, and an optional discussion appendix.
- Export printable PDF study material, including structured visual recap
  content.
- Strip the active reader bridge from exported documents.
- Record export history and store generated files in the persistent data
  volume.

## Annotation repair and version continuity

- Anchor selections with stable block IDs, exact quotes, surrounding text, and
  offsets.
- Reattach discussions and checked highlights when a new source version is
  imported or an edited revision changes block content.
- List annotations that could not be reattached automatically and let the
  owner select their new location from the repair workflow.

## Security and privacy

- Designed for one private owner account with multiple independent sessions.
- Password-protected login, server-side session records, CSRF validation on
  mutations, secure cookie handling, and login throttling.
- Sanitize imported HTML by removing scripts, event handlers, forms, embedded
  objects, unsafe URLs, traversal paths, and unapproved remote resources.
- Enforce a restrictive iframe Content Security Policy and allow only the
  network/media origins needed for supported content.
- Keep model provider secrets in server environment variables; settings store
  references, not secret values.
- Bind the included Compose deployment to loopback by default for use behind
  private HTTPS or a VPN.
- Run the production container as a non-root user and keep application data in
  the named `afterdraft-data` volume.

## Operations

- Multi-stage Docker image with a production frontend build and Fastify API.
- Container health check at `/health`, graceful shutdown, bounded JSON logs,
  and `unless-stopped` restart behavior.
- SQLite WAL mode with forward-only migrations and foreign-key enforcement.
- Documented consistent whole-volume backup, browsable HTML backup, isolated
  restore validation, and rollback procedures.
- `./restart-service.sh` rebuilds the current checkout, force-recreates the
  Compose service, waits for health, and prints the deployed image ID.
- `./restart-service.sh --check` validates Docker and deployment configuration
  without interrupting the running service.

## Installation

Requirements:

- Node.js 24+ for local development.
- Docker Engine with Docker Compose for production deployment.
- A strong owner password and a session secret of at least 32 characters.
- Provider API keys exposed through server environment variables for AI
  actions.

For development:

```sh
npm install
cp .env.example .env
npm run dev
```

For Compose deployment:

```sh
docker compose --env-file /path/to/afterdraft.env up -d --build
```

The Compose configuration publishes `127.0.0.1:4310` and is intended to sit
behind HTTPS or a private VPN.

## Upgrade and data notes

- Back up the complete `afterdraft-data` volume before upgrading.
- Database migrations run automatically and are forward-only. Test rollback
  against a restored copy of a pre-upgrade backup rather than pointing an older
  image at migrated production data.
- Imported source versions remain immutable. Direct edits are stored as
  separate revisions.
- Prompt and behavior overrides are stored in SQLite and therefore follow the
  normal whole-volume backup and restore contract.

## MVP boundaries

- AfterDraft is a single-owner private application, not a multi-tenant or
  collaborative hosted service.
- Import supports HTML and HTML-plus-assets ZIP bundles; PDF, EPUB, and live URL
  ingestion are not included in v0.1.0.
- External article resources are blocked unless explicitly supported or
  bundled with the import.
- AI actions require a compatible provider and server-side API key.
- “Checked” means manually retained as relevant; it is not automated factual
  verification.
- Vector search, arbitrary browser automation, shell/code execution tools, and
  general-purpose autonomous agents are outside the MVP.
