# AfterDraft v0.2.0 — Reader signals and revision-aware summaries

Released: 2026-08-11

AfterDraft v0.2.0 turns passive highlights and long discussion answers into
structured reader input. Important passages, open questions, reader comments,
and concise thread annotations are now first-class data. Document summaries
record the exact document and reader-signal state they used, so the reader can
see when an existing summary deserves review instead of silently replacing it.

This release also makes editing and discussion work together on desktop and
replaces the cursor-adjacent selection panel with a collision-aware action
popover and a bottom-docked Ask composer.

## What is new in v0.2.0

### Semantic highlights

- Classify a selected passage as **Important**, **Question**, or **Comment**.
- Important passages use the retained-evidence treatment and are supplied to
  future document-summary requests.
- Reader comments carry a required note and are supplied to summary requests
  as explicit reader context.
- Open questions remain visible in the article and sidebar but are labeled
  separately from summary evidence.
- Edit a highlight's type or note after creation, or remove the highlight.
- Distinguish the three types with labels and line/pattern treatments in
  addition to color, including accessible keyboard activation.
- Store block-local offsets with the exact quote and surrounding context so a
  particular occurrence can be restored when the same text appears more than
  once.
- Reapply semantic marks after article reflow, saved edits, and version
  migration while retaining the existing annotation-repair workflow when an
  exact automatic match is no longer possible.

### Concise thread annotations

- Give every passage-anchored root discussion an editable short annotation for
  the useful conclusion the reader wants to retain.
- Show a two-line article-side preview automatically, preferring the saved
  annotation, then an existing Compact result, then the latest assistant
  answer. The original answer remains available in the discussion pane.
- Draft a one- or two-sentence note from a definition, explanation, or longer
  answer without changing the assistant's original response.
- Use **Polish with AI** to tighten a draft with the lightweight `polish-note`
  route, then review the result before saving it.
- Save and remove annotations explicitly. Drafts remain local until saved, so
  AI output never writes into the article or knowledge model without the
  reader's confirmation.
- Copy any assistant answer directly from its discussion card.

### Summary freshness and reader input

- Document TL;DR, half-page, and visual-recap artifacts now record the source
  document version, saved edit revision, and reader-signal fingerprint used to
  generate them.
- Existing summaries are marked **Needs review** when the document version,
  saved edits, important highlights, or reader comments have changed.
- The UI explains which input changed and offers **Regenerate** or
  **Keep current**. Keeping the current result explicitly accepts the latest
  basis without spending another model request.
- Summary prompts receive typed **IMPORTANT**, **READER COMMENT**, and
  **OPEN QUESTION** sections. The generation contract asks the model to
  reflect important passages and reader comments while keeping unresolved
  questions distinct.
- Provenance is captured when generation starts, not when it finishes. A
  highlight or edit created during a long-running request therefore leaves the
  new artifact correctly marked for review.

### Edit and discuss together

- Desktop edit mode keeps the discussion sidebar available instead of turning
  the reader into an isolated editing screen.
- Selection-based Ask, Define, Explain, Compact, summary, visual, and Research
  actions remain available while editing. Highlight creation stays tied to the
  saved reading representation.
- **Save & Ask** saves pending operations before opening the grounded question,
  then restores the exact selected range and nearby scroll position in the
  refreshed article.
- The article iframe is locked while a save is in flight so late edit events
  cannot be lost behind the saved revision.
- Narrow screens keep the article readable and put editing/discussion controls
  in the existing drawer rather than trying to force a desktop split view.

### Selection workflow and Ask composer

- Position the selection-action popover relative to the complete selected
  passage, not the cursor, with a clear exclusion gap so it does not cover the
  text of interest.
- Measure and clamp the popover inside the article pane, choose above or below
  based on available room, and fall back to a reserved dock at the article edge
  farthest from the selection when neither side fits.
- Recalculate placement after article scrolling, window resizing, iframe
  reflow, and sidebar resizing.
- Keep the compact action stage separate from a bottom-docked Ask composer.
  Choosing **Ask** opens the question input, model selector, Send, and Close
  controls without immediately submitting the selected text.
- Reserve composer height in the article layout, reveal the stored exact
  selection when composing starts, and keep article scrolling enabled.
- Autofocus the Ask field, submit with Enter, and cancel with Escape, Close, or
  the existing background-dismiss behavior.
- Preserve the draft after a recoverable submission failure, reuse the request
  identifier for an ambiguous retry, and clear it only after successful
  submission or cancellation.
- On narrow screens, dock both stages at the bottom and replace the action strip
  with the composer rather than stacking them.
- Copy selected text from the action popover, including a fallback for browsers
  that block the modern Clipboard API.

## Complete supported feature set

### Library, import, and navigation

- Import a self-contained HTML document or an HTML-plus-assets ZIP bundle,
  choose an entry document when necessary, and retain local CSS, fonts, images,
  SVG, tables, and supported video.
- Reject unsafe scripts, handlers, forms, traversal paths, unsupported embeds,
  and unapproved remote resources before content reaches the reader.
- Deduplicate identical imports, retain immutable source versions, and migrate
  annotations forward when a new version is imported.
- Organize articles into named groups, move them back to the ungrouped shelf,
  and permanently delete an article through title confirmation.
- Search article text, AI answers, and derived artifacts with result-type
  filters; persist reading progress and reopen active material.

### Reading and selection actions

- Read sanitized content in a CSP-restricted iframe while preserving bundled
  article styling and media.
- Resize the desktop discussion pane with a keyboard-accessible divider or use
  the synchronized drawer on narrow screens.
- Run Copy, Define, Explain, Explain for a 14-year-old, Ask, Highlight,
  Compact, TL;DR, Half-page, Visual recap, Visualize, and Research from a text
  selection.
- Select supported images, SVG, tables, figures, and videos as visual anchors;
  capture table and figure representations for compatible vision actions.
- Override the routed model for an individual request and stop an active
  streamed response.
- Navigate bidirectionally between an article mark and its related highlight,
  discussion, or annotation entry.

### Discussions and knowledge artifacts

- Keep durable selection-rooted threads with Markdown answers, nested questions
  about an assistant message, and replies that retain branch ancestry.
- Preserve definition threads, general discussions, semantic highlights,
  reader comments, and concise thread annotations as distinct knowledge.
- Create TL;DR, half-page, compact, visual-recap, and visualization artifacts at
  supported document, section, answer, or thread scopes.
- Keep document-level TL;DR, half-page, and visual recap as replaceable
  singleton views while retaining request provenance and freshness state.
- Pin or unpin artifacts, render accessible structured diagrams and visual
  recaps, and include promoted material in exports and later context.
- Preserve source references, citations, tool events, fallback attempts,
  latency, token use, model metadata, and run status.

### AI providers, routing, prompts, and context

- Use native OpenAI Responses, generic OpenAI-compatible Chat Completions, or
  OpenRouter-compatible providers with server-side environment-variable key
  references.
- Route actions to configurable GPT-5.6 models, expose model readiness, and
  allow a per-request override without changing the saved route.
- Stream response deltas and show provider, model, context tier, tool use, and
  fallback state in the reader.
- Build quick, study, canonical, and branch-digest context tiers for long
  documents and discussions; cache article context and invalidate it after
  relevant edits or setting changes.
- Edit the source-controlled prompt components from Settings with required
  variable validation, unknown-placeholder rejection, and reset-to-default.
- Configure context budgets, full-document thresholds, conversation ancestry,
  digest sizes, and routing behavior without exposing provider secrets.

### Revisioned article editing

- Edit supported text and heading blocks directly while retaining the immutable
  imported source.
- Apply bold, italic, and underline to exact ranges; create foldable heading
  sections and choose their initial state.
- Add or update labels, numbering, and captions for figures, tables, images,
  SVG, and video blocks.
- Resize imported raster images proportionally within safe article bounds.
- Review pending operations before saving, cancel an edit session, browse the
  immutable edit history, and restore an earlier revision without deleting
  later revisions.
- Use the effective edited document for reading, AI context, search, anchoring,
  and export.

### Export and portability

- Export self-contained annotated HTML with embedded local assets, selected
  reader notes, promoted artifacts, and optional full discussion history.
- Export a Markdown study notebook with source metadata, highlights, notes,
  promoted artifacts, and an optional discussion appendix.
- Export printable PDF study material, including structured visual-recap
  content.
- Strip the interactive reader bridge from exported files and record generated
  exports in persistent storage.

### Security and operations

- Run as a private single-owner application with password login, independent
  server-side sessions, CSRF checks on mutations, secure cookies, and login
  throttling.
- Keep provider keys in server environment variables and never return secret
  values to the browser or persist them as settings.
- Deploy a non-root multi-stage container with persistent SQLite/filesystem
  state, WAL mode, forward-only migrations, bounded logs, health checks, and
  graceful shutdown.
- Back up, restore, and validate the complete persistent volume using the
  documented operations scripts.
- Rebuild and force-recreate the service with `./restart-service.sh`; use
  `./restart-service.sh --check` to validate prerequisites without interrupting
  the running container.

## Database migration and compatibility

Migration 11 runs automatically on startup and is forward-only. It:

- adds a semantic `kind` to highlights and maps legacy colors to **Important**,
  **Question**, or **Comment** while preserving the stored notes;
- adds the optional saved `annotation_text` field to discussion threads;
- adds document-version, edit-revision, and reader-signal basis fields to
  artifacts so summary freshness can be evaluated deterministically;
- normalizes block-local anchor coordinates written by older imports while
  preserving exact repeated-text occurrences; and
- safely preserves image, table, and other zero-length visual anchors across
  re-imports and saved edits, or exposes them for repair when their block was
  removed.

Existing articles, source versions, edit history, discussions, highlights,
artifacts, exports, provider settings, prompt overrides, and sessions remain in
place. Older summary artifacts without complete basis metadata are shown with
an **Unknown** freshness state until regenerated or explicitly accepted.

Back up the complete `afterdraft-data` volume before upgrading. Because schema
migrations are forward-only, test rollback by restoring a pre-upgrade backup
instead of pointing a v0.1 image at a database already migrated by v0.2.

## Verification

The v0.2.0 release gate covers:

- `npm run typecheck` for the shared contracts, server, and web app;
- `npm run lint` across the repository;
- `npm test`, including semantic highlight CRUD and validation, exact repeated
  range anchors, migration backfill, typed AI context, summary provenance and
  freshness, note polishing, resize-edit API coverage, iframe selection marks,
  retry identifiers, and the new reader controls;
- `npm run build` for all workspaces; and
- `./restart-service.sh --check`, a clean production rebuild/recreation, and the
  deployed service health check.

The optional live-provider integration test remains opt-in because it requires
configured external credentials and can incur provider usage.

## Deferred work and known limitations

- v0.2.0 does not add a master AI session that rewrites the whole article from
  discussion results. Moving a note or answer into the article remains an
  explicit reader editing decision.
- v0.2.0 does not use AI to decide semantically whether an existing summary is
  already sufficient after source or reader-signal changes. Freshness is
  deterministic; the reader chooses **Keep current** or **Regenerate**.
- AI-polished thread annotations are suggestions and require an explicit save.
  They are not automatically inserted into the article or converted into
  highlights.
- Desktop can show editing and discussion together; narrow screens use the
  drawer because a persistent side-by-side layout would compromise reading
  space.
- AfterDraft remains a private single-owner workspace rather than a multi-user
  collaborative publishing service.
- PDF, EPUB, and live-URL ingestion, vector search, arbitrary browser or shell
  tools, and general-purpose autonomous agents remain outside this release.
