# AfterDraft v0.5.0 — Complete papers from PDF and public sources

AfterDraft v0.5.0 extends the academic importer with standalone paper PDFs and
public article URLs/DOIs. Both enter the same asynchronous preview, deterministic
diagnostics, optional model review, publication, annotation, and edit workflow as
DOCX, TeX, arXiv, and HTML imports.

## Standalone PDF import

- Accept born-digital or scanned PDFs up to 100 MiB and 100 pages, rejecting
  encrypted, invalid, or incompletely rendered inputs instead of truncating.
- Reconstruct selectable reading blocks from positioned native text with
  deterministic single/two-column ordering.
- Extract reliably bounded raster figures near their source position while
  retaining every accepted PDF page as a folded, enlargeable 144-DPI image.
- Reconstruct multi-line front-matter titles and preserve the title as the
  library entry name.
- Treat equation, table, citation, and scanned-page semantics conservatively:
  uncertain content remains visible in the source-page fallback and is never
  invented by a model.
- Reuse published page fallbacks as optional VLM comparison evidence rather
  than duplicating large page images in the conversion archive.

## Public article and DOI import

- Fetch public HTTPS HTML, JATS, or direct PDF sources without browser cookies,
  publisher login state, JavaScript execution, proxies, or authentication
  headers.
- Normalize semantic article content, MathML, figures, tables, citations,
  fragments, lazy images, responsive image sources, and bounded local CSS/assets
  into the ordinary AfterDraft reader format.
- Reject private/reserved network destinations on every DNS resolution and
  redirect, including IPv4-mapped/transition IPv6 forms; pin each validated
  public address while retaining hostname verification.
- Reject bot challenges, login/paywall shells, abstract-only pages, unsafe
  redirects, signed URLs, ZIP bombs, and unsupported/mismatched content.
- When a requested publisher blocks access, optionally resolve the exact DOI to
  an official open-access PMC/Europe PMC full-text record. Requested and resolved
  URLs, DOI, PMCID, license, hashes, adapter, and redirect provenance remain
  visible. Repository ZIPs are inventoried safely and only JATS-referenced
  figures are extracted; unrelated supplements are ignored.
- Never bypass access controls. If no trusted complete source exists, the job
  asks for the paper PDF or a saved HTML bundle.

## Review and editing

Source/page evidence uses the existing Luna/Terra/Sol review routes and bounded
call policy. After publication, figures and tables can be moved between exact
paragraph boundaries, resized/aligned/folded, captioned, and given alt text with
the existing revisioned editor.

## Validation

The release gate includes the supplied IEEE manuscript exported to PDF: its full
title, all 14 pages, two-column reading order, seven figures, and folded page
fallbacks are retained. The supplied Wiley URL is expected to trigger its bot
boundary and resolve only through the matching CC BY Europe PMC record for DOI
`10.1515/nanoph-2023-0852`, including all 11 referenced figure/equation images.

## Migration and recovery

Database migration 16 extends durable academic import jobs with `pdf` and `url`
source kinds while preserving existing jobs and findings. The worker remains
stateless and has no host port; `afterdraft-data` remains the complete durable
backup unit. Take and verify a pre-upgrade backup before deploying this release.
